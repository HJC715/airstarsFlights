# 驗收紀錄

2026-10-19（Asia/Taipei），於本次雲端實例使用 Node 24、Python 3.12 與 Chromium 154 驗證。

- `node --test tests/*.test.mjs`：三份測試檔通過，共 20 個案例。涵蓋完整資料、八機型容量、IANA/DST、直飛及轉機、固定庫存、TWD 公式、混艙行李、成人及旅遊證件驗證、空訂單、付款成功／失敗及重複提交、不可變快照、完整重設、各幣別明細與摘要尾差。
- 附件與 `docs/PRD.md` 的 SHA-256 相同；32 機場與 59 對／118 筆單向固定班表逐欄比對符合。另檢查 43,070 筆全年時區往返、1,024 組起訖搜尋及 1,471 個可用轉機組合。轉機依 Part 1 §5.2 採 90 分鐘至 18 小時；測試卡依 Part 1 §13 使用 DEMO-*。
- `node tests/browser.mjs`：四條完整流程通過，無未捕捉 JavaScript 錯誤。涵蓋桌機單程、390px 手機付款失敗後重試、雙人多城市更換部分航程、NRT→TPE→LHR 逐段混艙。實際操作搜尋、旅客、行李、手動／自動選位、特殊餐、確認、付款、PNR、票號及下載 PDF。
- 上述瀏覽器驗收也確認：改票種保留已選服務並重新計價；改單一航段艙等僅清該段座位及餐點，保留其他段及加購行李；付款完成後可用幣別選單，成功頁與 PDF 同步顯示 EUR；返回首頁確實清空價格、旅客、服務與確認資料。
- `node tests/ui.mjs`：320px 來回訂票全流程、鍵盤焦點、44px 座位、座位橫捲及手機摘要展開狀態保留；無航班日期仍提供七日期帶及鄰日恢復；768px 四段兩成人刪除中間航程後，其餘航程 ID、選班、兩位旅客的座位／餐點／行李全部保留。無 JavaScript 錯誤及整頁橫向溢出。
- `node tests/pdf.mjs`：9 成人、4 個雙段轉機航程，共 72 筆座位／餐飲、36 筆方向行李，產生 13 頁 A4 直式 PDF，約 3.12 MB。驗證付款快照、切換幣別、PDF 工具載入失敗後重試；各頁均有模擬無效聲明及頁碼。另以 pdfinfo／pdftoppm 確認頁面格式及中文可讀。PDF 採頁面影像，文字不可選取。
- 透過只提供本專案檔案、綁定 127.0.0.1 的測試伺服器驗證 `/airstarsFlights/` 子路徑：ES Modules、圖片、手機 reduced-motion 搜尋正常，無 HTTP 資產錯誤或整頁橫向溢出。

付款驗收使用文件允許的顯式 QA URL 強制成功及失敗；一般模式仍採規定的隨機 3–5 秒及 98%／2% 機率。一般付款機率邊界另有單元測試。

網站本身無需安裝套件、無 build、後端或外部 runtime API，必要 PDF 工具、中文字型與授權均隨專案提供。截圖及 PDF 驗收產物位於 `/tmp/air-stars-results/`，不納入儲存庫。GitHub Pages 實際發布尚未執行，本次完成本機 HTTP 與專案子路徑驗證。
