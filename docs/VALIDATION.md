`node --test tests/*.test.mjs`：七份檔案、39 個案例通過。涵蓋固定班表／時區、庫存與價格、旅客／證件、付款邊界與快照、匯率尾差，以及本次新增的票種比較、多人選位／取消補位、選填座位、特殊餐與主菜分離、共用確認卡。

完整 32 機場、38 雙向航線、118 單向班表及八機型座位容量維持一致。原始附件與 `docs/PRD.md` 的 SHA-256 相同；新要求以 `docs/UPDATES_2026-10-19.md` 記錄並優先於舊規則。

## 實際瀏覽器流程

- `node tests/browser.mjs`：四條完整流程通過。桌機單程、390px 手機失敗重試、雙人多城市、Y/C 混艙轉機，均完成搜尋、票種、旅客、行李、座位、特殊餐、確認、授權成功、手動完成、PNR／票號及 PDF。確認付款結束仍停第七步，按完成後才進行程確認，返回首頁會清空訂單。無未捕捉 JavaScript 錯誤。
- `node tests/ui.mjs`：320px 三成人來回的依序選位、取消前兩人後依序補位、下一航程完全不選位也能繼續；只呈現所購艙等、上下航段按鈕可見、44px 座位、焦點／橫捲／摘要狀態保留。另確認無航班日期帶恢復，以及 768px 四段兩成人刪中間段後保留其他航程與服務。
- 同一 UI 驗收確認 JCB 預設、hover、已選狀態的深色字與背景對比至少 4.5；付款頁不再顯示成功率、等待秒數或實際扣款零元；附加服務為零時摘要不顯示該列，同頁改選不重播主要卡片動畫。
- `node tests/fare-layout.mjs`：1440／390／320px 的三票種比較無整頁溢出，手機可滑到彈性票種，卡片各權益列水平對齊；改選保留票種列橫捲位置。
- `node tests/review-layout.mjs`：320／768／1440px 的訂單確認與成功頁通過。時間軸、鍵盤展開票種權益、44px 修改按鈕、未選座位提示、完成快照票號與幣別正確，無整頁溢出。
- 首頁於 1440／390px 實際截圖檢查，新航空形象圖沒有機身文字；手機將說明文字與飛機移至不同區域。無載入錯誤或整頁橫向溢出。

## PDF 與執行

`node tests/pdf.mjs`：9 成人、4 個雙段轉機航程，共 72 筆航段服務，產生 13 頁 A4 直式 PDF，約 3.51 MB。測試包含刻意未選座位、預設無特殊需求、商務早餐、獨立特殊餐、付款快照及所選幣別；沒有 undefined、錯收未選座位費或缺少頁面聲明。另驗證 PDF 工具載入失敗可重試，並以 pdfinfo／pdftoppm 檢查 A4、中文及每頁模擬聲明。

付款瀏覽器驗收使用 PRD 允許的顯式 QA URL 強制成功及失敗；一般模式仍採隨機 3–5 秒、98%／2% 機率，邊界另有單元測試。網站本身不需要套件安裝、編譯、後端或外部 runtime API，PDF 工具、中文字型與授權均隨專案提供。所有新模組與樣式使用專案相對路徑，維持 GitHub Pages 子路徑部署方式。
